# GayBoi5000

Meteor-style Click GUI for CheatUtils on Minecraft 26.2 (Fabric).

## Use
1. Install Fabric Loader, Fabric API, CheatUtils, and this mod.
2. Launch with CheatUtils loaded (HTTP API on port 5005+).
3. Press **Right Shift**.
4. **Left click** = toggle · **Right click** = settings.
